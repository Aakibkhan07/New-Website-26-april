## Overview
A completely free, AI-powered chart analysis tool integrated into your TradeMetrix website. Uses pure JavaScript technical analysis with zero API costs and 100% data privacy.

- **Bollinger Bands** - Volatility and support/resistance

### 5. Support & Resistance
- Automatic level detection
- Key price zones

### 6. Trading Signals

## How It Works

1. **Upload Chart Image**
   - User selects trading chart image
   - Preview displayed immediately

2. **Analyze Patterns**
   - JavaScript engine processes image
   - Detects colors, patterns, trends
   - Calculates technical indicators

3. **Generate Report**
   - RSI, MACD, Bollinger Bands calculated
   - Support & resistance levels detected
   - Candlestick patterns identified
   - Price prediction generated

4. **Display Results**
   - Clean, organized results dashboard
   - Key metrics highlighted
   - Recommendations provided
   - Risk disclaimers included
